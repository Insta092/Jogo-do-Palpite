# 🎯 Jogo de Adivinhação: Acerte o Número! 🔢

Este projeto foi criado durante a minha jornada de aprendizado em **JavaScript**, com o objetivo de praticar **lógica, controle de fluxo e interação com o usuário** através do navegador.

O desafio é simples e divertido: **tente adivinhar um número aleatório entre 0 e 100**, com a menor quantidade de tentativas possível!

---

## 🕹️ Como funciona?

- O jogo gera automaticamente um **número secreto entre 0 e 100**.
- O jogador digita um palpite.
- O sistema responde se o número é **maior, menor ou igual** ao chute.
- O jogo mostra **quantas tentativas** você levou para acertar.

---

## 🔧 Tecnologias Utilizadas

- 🌐 **HTML5** – estrutura da página
- 🎨 **CSS3** – estilo visual simples e funcional
- ⚙️ **JavaScript** – lógica do jogo e interação com o usuário

---

## 💡 O que eu aprendi com esse projeto

- Como gerar números aleatórios com `Math.random()`  
- Manipular elementos HTML com JavaScript  
- Trabalhar com **eventos de clique** e **inputs** do usuário  
- Usar condicionais e variáveis para criar uma **experiência de jogo**
